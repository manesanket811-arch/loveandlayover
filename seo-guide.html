📋 SEO Checklist for New Pages

When adding new destination guides or blog posts, ensure:

  • Unique, descriptive title tag (50-60 characters)
  • Meta description with target keywords (150-160 characters)
  • H1 tag matching or close to title
  • H2/H3 tags for content structure
  • At least 2-3 internal links to other destination/blog pages
  • BreadcrumbList schema markup
  • Relevant schema for content type (Article, TravelAction, etc.)
  • Open Graph tags (og:title, og:description, og:image, og:url)
  • Twitter card tags
  • Canonical URL pointing to correct version
  • Mobile responsiveness test
  • At least one CTA (Newsletter, Itinerary Builder, or Related Pages)

🔐 Verification & Ownership

Google Search Console Setup:

To verify site ownership with Google, add one of these verification methods:

<meta name="google-site-verification" content="[YOUR_VERIFICATION_CODE]" />

Then submit to GSC for monitoring ranking, indexing, and search traffic.
