GA4 Conversion Tracking Setup

Track newsletter signups, contact form submissions, and other key user actions to measure campaign performance and user engagement.

What Are Conversions?

A conversion is any important action a user takes on your website. Examples:

  • Newsletter signup: User subscribes to weekly travel tips
  • Contact form submission: User sends a message or feedback
  • Testimonial submission: User shares their travel experience
  • Page visits: User views destination guide or blog post
  • Video play: User watches travel content
  • Itinerary creation: User builds a custom trip plan

Tracking conversions lets you see which marketing channels, content pieces, and user journeys drive the most valuable actions.

Key Conversions to Track

1. Newsletter Signup

Occurs: User submits email to newsletter form (newsletter.html)

Why track: Newsletter subscribers are your most engaged audience

Goal: 5-10% of monthly visitors should signup

2. Contact Form Submission

Occurs: User submits contact form (homepage footer or contact page)

Why track: Direct inquiries indicate strong interest

Goal: 1-3% of monthly visitors should submit contact

3. Testimonial Submission

Occurs: User submits a travel testimonial (testimonials.html)

Why track: User-generated content signals trust and community

Goal: 2-5 testimonials per month from 500+ monthly users

4. Page Engagement (Secondary)

Occurs: User spends 30+ seconds on destination or blog page

Why track: Indicates content quality and user interest

Goal: 60%+ of users should engage with content

5. Video View (Secondary)

Occurs: User watches 50%+ of an embedded travel video

Why track: Video engagement predicts interest in video content

Goal: 20-30% of homepage visitors watch video

5Newsletter Signup Event

Add this code to newsletter.html (in the form submission handler):

gtag('event', 'newsletter_signup', { 'email': email_address, 'signup_method': 'web_form', 'timestamp': new Date().toISOString() });

Location in newsletter.html: Find the `document.getElementById('newsletterForm').addEventListener('submit'...)` section and add the gtag call after form submission succeeds.

6Contact Form Event

Add this code to your contact form (homepage footer form):

gtag('event', 'contact_form_submission', { 'form_type': 'contact', 'message_length': messageText.length, 'timestamp': new Date().toISOString() });

Location: Add to the form submission handler before redirecting or resetting the form.

7Testimonial Event

Add this code to testimonials.html:

gtag('event', 'testimonial_submission', { 'form_type': 'testimonial', 'rating': ratingValue, 'destination': destinationValue, 'timestamp': new Date().toISOString() });

Location: Add to the form submission handler in testimonials.html.

Note: These code additions will be implemented in the next development iteration to ensure proper testing and validation before deployment.

Troubleshooting Conversion Events

Issue: Conversions showing 0 after 24 hours

Diagnosis: Event tracking code may not be firing. Check browser console for errors.

Solution:

  1. Open browser DevTools (F12) â†’ Console tab
  2. Submit a test form (newsletter or contact)
  3. Look for errors related to gtag or missing functions
  4. Verify gtag is properly initialized in page head
  5. Re-test after 1 hour (events take time to process)

Issue: Conversion rate looks unrealistic (90%+ conversions)

Diagnosis: Event firing on every page load instead of only on form submission.

Solution: Ensure gtag event is inside form submit handler, not in page-load code. Should only fire when user clicks submit button.

Issue: Can't see breakdown by traffic source

Diagnosis: Conversion report may not have the right dimensions.

Solution: In GA4 Conversions report, click the pencil icon â†’ add "Source / medium" dimension to see which channels drive conversions.

Reference: Event Parameter Guide

Event Parameters You Can Track

email: User's email address (for newsletter tracking)
form_type: Type of form submitted (contact, newsletter, testimonial)
signup_method: How user signed up (web_form, modal, popup)
message_length: Character count of contact message
rating: Star rating from testimonial form
destination: Destination mentioned in testimonial
timestamp: When the event occurred

These custom parameters help you segment and understand conversion quality. For example, you could see that 5-star testimonials convert at a higher rate than 3-star testimonials.
