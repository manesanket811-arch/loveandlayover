### 4.1 Performance Optimization
**Priority Actions:**

```
A. Image Optimization
   - Compress all images (use TinyPNG, ImageOptim)
   - Use WebP format (faster loading)
   - Lazy load images (load as user scrolls)
   - Add responsive images (different sizes for mobile)
   
B. Code Optimization
   - Minify CSS/JavaScript
```
